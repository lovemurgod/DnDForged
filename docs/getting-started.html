Your first game

Let’s get your table ready.

Host directly in your browser using Play Online (P2P) and Session Prep with zero downloads—or use the optional Windows Desktop App for offline LAN play, local SSD storage, and Cloudflare Tunnels. Everyone else opens your shared game link in a browser.

Recommended • Zero Install

Option 1: Host Online in Your Browser (P2P).

  1. 1

    Prep your campaign in Session Prep

    Open Session Prep in Chrome, Edge, Firefox, or Safari to create a campaign, build characters, or import maps and homebrew. Your data saves locally in your browser (or directly to a local folder in Chrome/Edge).

  2. 2

    Launch your P2P table

    Click Open Table in Browser from Session Prep (or open Play Online and select Host Game (GM)) to start a live Direct P2P room with a unique Room Code.

  3. 3

    Copy and share your invite link

    Click Copy Invite Link and send it to your party. Players open it in any browser and join straight into your tabletop with zero installs or accounts.

Hosting from a Phone or Tablet? 3 Crucial Tips

You can host directly from mobile Safari or Chrome with zero desktop downloads. Because mobile operating systems aggressively suspend background tasks to save power, keep these three rules in mind:

1. Keep Screen Awake

If your screen locks or you switch apps, mobile browsers suspend WebRTC and disconnect your players. Set Auto-Lock (iOS Safari) or Screen Timeout (Android Chrome) to “Never” or 30m during sessions.

2. Avoid Private Tabs

Private/Incognito mode wipes local IndexedDB campaign storage when closed. Use regular tabs, and tap Export Campaign in Session Prep to save quick JSON backups to iCloud or Google Drive.

3. Turn on Eco Mode

Inside the tabletop, tap More (☰) → Battery / Eco Mode to pause heavy WebGL weather particles and 3D dice physics, keeping your phone cool and saving battery throughout the game.

GM Workflow: Mobile is great for running live combat, rolling attacks, and moving tokens with tap-to-place. Detailed map & wall setup is easiest on desktop or iPad. Full Mobile Guide

Browser P2P vs. Offline App

Browser P2P is the fastest way to play online. If you’re running an in-person TV table without internet, or if a player’s strict firewall blocks P2P, use the optional Windows Desktop App below.

Optional • Offline & Desktop Host

Option 2: Host with the Windows Desktop App.

  1. 1

    Download and open ForgeDVTT

    Download the Windows installer and follow the prompts. Open ForgeDVTT when installation finishes.

    Download Windows Installer Get on itch.io
    First time on Windows? If prompted by Windows SmartScreen, click More info and select Run anyway. Downloads are verified directly from our official release, or install safely via itch.io.
  2. 2

    Start your local server

    In the app’s Hosting & Server tab, click Start Server. The server indicator will turn green once the local tabletop host is running on your machine.

  3. 3

    Start your online player tunnel

    Click Start Online Tunnel (leave the token blank for recommended quick setup). Wait a few moments for your secure player link to generate.

  4. 4

    Open your tabletop & share the link

    Choose Open VTT Window (or Open in Browser) to launch your Game Master view. Click Copy Link in the app and send the active address to your group.

  5. 5

    Get your table ready

    Set a Game Master password in the login window to secure host controls. Then click the Map icon () on the left toolbar to load a battlemap and place character or creature tokens on the grid.

What’s a tunnel?

It’s a secure connection that lets your friends reach the game running on your computer. ForgeDVTT starts it for you; you don’t need to change your router settings.

Cloudflare setup details

For players

Your Game Master sends the link.

Open it in Chrome, Edge, Firefox, or Safari on your computer, tablet, or phone. You don’t need to install ForgeDVTT or create a website account. Enter your Player Name, choose the Player role, and click Enter Tabletop. Once inside the table, open your character sheet from the side panel or click your assigned token. (On phones and tablets, you can optionally tap Add to Home Screen for a borderless fullscreen experience).

If something gets stuck

A few quick things to check.

The game link isn’t appearing.

Check that the local server is running, then try Start Online Tunnel again. Wait for the app to show the active link before copying it.

My players can’t open the link.

Make sure the computer hosting the game is online and ForgeDVTT remains open with the tunnel active. Copy the current link from the app and send it again.

The link changed after I restarted ForgeDVTT.

A no-token Quick Tunnel uses a temporary link. Copy the new link shown in the app and send it to your players. If you need a stable address, see the optional Cloudflare setup in the Guide.

Need more help? Read Cloudflare hosting help or search the Guide.

Performance & Hardware

System Requirements

ForgeDVTT runs directly in any modern web browser for both GMs and players. The optional Offline Desktop App runs on Windows 10/11 for local LAN tables and dedicated hosting.

Game Master (Browser P2P or Offline Windows App)

Host online in any modern browser, or use Windows 10/11 (64-bit, 4 GB+ RAM) for offline LAN play and dedicated local SSD storage.

Players (Web Browser)

Any modern browser on PC, Mac, Linux, iPad, Android, or Chromebook. Zero installation required to join.
