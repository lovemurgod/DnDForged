Performance & Hardware

System Requirements

ForgeDVTT is designed for tabletop freedom. The Game Master hosts from Windows, while players join instantly on any modern computer, tablet, or phone with zero installation.

Game Master (Windows Host)

Windows 10/11 (64-bit), 4 GB+ RAM, 2.0 GHz dual-core CPU. Runs the server and stores your campaign data locally.

Players (Web Browser)

Any modern browser on PC, Mac, Linux, iPad, Android, or Chromebook. Zero installation required to join.

Low Feature Use: Tactical Essentials

Static image battlemaps, 2D token movement, character sheets, and standard dice rolling.
