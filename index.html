A tabletop for your next D&D night

One DM to Run it.One Party to Play it.One VTT to Forge it All—and in your minds, display it.

ForgeD is a virtual tabletop: a shared online space for your D&D game. The Game Master hosts from the Windows app; players open your game link in a browser.

Download for WindowsSee how to start a game

For Game Masters on Windows 10 or 11. Players don’t need to install the app.

First time on Windows? If prompted by Windows SmartScreen, click More info and select Run anyway.

Performance & Hardware

System Requirements

ForgeD is designed for tabletop freedom. The Game Master hosts from Windows, while players join instantly on any modern computer, tablet, or phone with zero installation.

Low Feature Use: Tactical Essentials

Static image battlemaps, 2D token movement, character sheets, and standard dice rolling.

Lightweight
Component Game Master (Windows App) Players (Web Browser)
Operating System Windows 10 or 11 (64-bit) Any (Windows, macOS, iOS, Android, Linux, ChromeOS)
Processor (CPU) Dual-Core 2.0 GHz (Intel Core i3 / AMD Ryzen 3 or newer) Standard modern mobile, tablet, or desktop processor
Memory (RAM) 4 GB RAM 2 GB RAM
Graphics (GPU) Integrated graphics (Intel UHD / AMD Radeon) with WebGL support Any modern browser with WebGL enabled
Storage ~500 MB (app installer) + room for maps Zero install (no storage required)
Internet 3–5 Mbps stable upload speed Standard broadband or mobile data (1–2 Mbps)

High Feature Use: Cinematic Immersion

4K animated video battlemaps, real-time line-of-sight & darkness, multi-layer weather particles, and 3D physics dice.

Cinematic
Component Game Master (Windows App) Players (Web Browser)
Operating System Windows 10 or 11 (64-bit) Windows, macOS, Linux, iPadOS, Android
Processor (CPU) Quad-Core 3.0+ GHz (Intel Core i5 / AMD Ryzen 5 or newer) Quad-Core desktop CPU or modern tablet (iPad Air/Pro, Galaxy Tab)
Memory (RAM) 8 GB to 16 GB RAM (smooth multi-tab caching & popouts) 4 GB to 8 GB RAM
Graphics (GPU) Dedicated GPU (NVIDIA GTX 1050 / AMD RX 560 or newer) or Intel Iris Xe Dedicated GPU or modern integrated graphics with WebGL 2.0
Storage 5 GB+ free SSD space (for video maps & media cache) Standard browser cache
Internet 10+ Mbps upload speed (for streaming video maps to 4–6 players) Broadband connection (5+ Mbps download)
