Server & Cloudflare Tunnels

Control Center • Tab 1

ForgeD runs a high-performance local Express server and uses Cloudflare to provide players with an instant, secure web route into your session without changing router port-forwarding rules.

Express Engine & Loopback Port 5050
Local Core

When you click Start Server in the Control Center, the app spins up a bundled Node.js HTTP and WebSocket server on loopback port 5050:

  • Local Web Address: Accessible internally at http://localhost:5050 or http://127.0.0.1:5050.
  • Cryptographic Session Tokens: The desktop app protects local API calls with x-server-secret and authenticates the Game Master session using salted PBKDF2 hash tokens.
  • Windows Firewall: If prompted on first launch, allow ForgeD on Private Networks. Public incoming ports are never exposed because the tunnel routes outbound traffic securely.
Cloudflare Hosting Modes
Dual Tunnels

ForgeD supports two tunnel modes to connect external players to your session:

  • Quick Tunnel (Default & Recommended): Leave the token field blank and click Start Online Tunnel. The launcher establishes an ephemeral, zero-config Cloudflare tunnel (e.g. https://random-name.trycloudflare.com). It requires zero accounts and generates your active player link in ~5 seconds.
  • Custom Domain (Persistent URL): If you own a domain managed in Cloudflare Zero Trust, create a Cloudflare Tunnel routed to service http://127.0.0.1:5050. Paste the tunnel token and your custom hostname into ForgeD for a permanent session URL (e.g. https://dnd.yourdomain.com).
Session Controls & Live Diagnostics

Tabletop Launch Options

Once the server is running, you have two ways to open your GM view:

  • Open VTT Window: Opens an isolated native desktop window running the client with hardware-accelerated WebGL.
  • Open in Browser: Opens the local URL in your system's default browser (Chrome, Edge, Firefox, Brave).
  • Copy Link: Copies the active player invite URL directly to your Windows clipboard.

Live Network Monitor

The Control Center provides real-time session feedback:

  • Active Players: Shows live count of connected browser WebSockets.
  • Tunnel Status: Displays latency, tunnel uptime, and connection health.
  • Log Stream: Inspect server events, file uploads, and WebSocket sync traffic in real time.

Campaign Data & Backups

Control Center • Tab 2

All campaign maps, characters, tokens, handouts, and chat logs are stored locally on your computer in standard JSON format. You retain 100% data ownership.

Data Directory Architecture

The .dndforged-data Folder

ForgeD stores all user content in the .dndforged-data directory located inside your application folder or user profile:

  • campaigns.json — Contains all scenes, tactical grids, placed tokens, fog-of-war states, and character sheets.
  • campaigns.json.bak — Automated rolling safety backup created every time the server starts or saves.
  • chat-log.json — Persistent history of all dice rolls, public messages, and GM whispers.
  • assets/ — Uploaded battlemap graphics, custom token portraits, audio files, and video loops.
  • auth.json — Cryptographic hash of your Game Master password.

Disaster Recovery & PC Migration

How to protect and transfer your world with zero data loss:

  • 1-Click Backup: In the GM Dashboard tab, click Open Data Folder. Simply copy the .dndforged-data folder to Google Drive, OneDrive, or a USB drive.
  • Restoring a Corrupt File: If a power loss occurs during play, rename campaigns.json.bak to campaigns.json and restart the server.
  • Migrating to a New PC: Install ForgeD on the new computer, copy your .dndforged-data directory over, and launch the app. All campaigns restore instantly.

Monsters, Bosses & Attack Syntax

Homebrew Studio

ForgeD features a natural-language attack parser. Writing your actions in standard 5e format allows the VTT to automatically extract to-hit bonuses, reach, damage formulas, and save DCs into single-click combat buttons.

Action Syntax Engine & Regex Rules

When adding an action in the Creature Editor, use the following standard formats to enable automatic dice macros:

Melee & Ranged Weapon Attacks

Format syntax:

Melee Weapon Attack: +8 to hit, reach 10 ft., one target. Hit: 15 (2d8 + 6) slashing damage plus 7 (2d6) fire damage.
  • To-Hit: +8 to hit creates a d20 + 8 attack roll button.
  • Damage Formula: 15 (2d8 + 6) slashing creates a 2d8 + 6 slashing damage roll.
  • Secondary Riders: Adding plus 7 (2d6) fire damage generates a secondary damage button in chat.

Saving Throw Area Attacks

Format syntax:

Fire Breath (Recharge 5–6). Each creature in a 30-foot cone must make a DC 16 Dexterity saving throw, taking 42 (12d6) fire damage on a failed save, or half as much on a successful one.
  • Save Prompt: DC 16 Dexterity automatically generates a 1-click player saving throw prompt in the multiplayer chat log.
  • Recharge Die: (Recharge 5–6) creates an automated recharge roll button in the sheet header.
Advanced Boss Mechanics: Multiattack & Legendary Actions
Multiattack Parser
1-Click Combo

ForgeD parses natural language multiattack lines into automated routine buttons:

  • Example String: The dragon makes three attacks: one with its Bite and two with its Claws.
  • Execution Card: Clicking Multiattack on the creature sheet broadcasts an action card with direct roll triggers for each weapon in the routine, saving significant GM combat time.
Legendary & Lair Actions
Action Budget

Configure true epic boss encounters with flexible resource pools:

  • Legendary Pool: Toggle Legendary Actions to give the monster a 3-pip action tracker that refreshes at the start of its turn.
  • Cost Modifiers: Actions marked with (Costs 2 Actions) automatically deduct two charges when executed.
  • Lair Action Triggers: Special initiative count 20 triggers broadcast lair effects directly to the combat carousel.

Weapons, Armor & Magic Gear

Equipment Studio

ForgeD's equipment engine dynamically calculates Armor Class, weapon attack macros, and weight encumbrance based on 5e rules and item properties.

Dynamic Armor Class (AC) Rules

Armor Categories

When creating homebrew armor, select the category to trigger exact AC math:

  • Light: Base AC + character's full DEX modifier (e.g. 12 + DEX).
  • Medium: Base AC + DEX modifier, automatically capped at +2 (e.g. 14 + min(DEX, 2)).
  • Heavy: Flat base AC with zero DEX bonus (e.g. 18). Automatically flags the stealth disadvantage indicator.
  • Shield: Checking the Equip box adds a flat +2 AC bonus.

Unarmored Defense Formulas

Homebrew classes or magical tattoos can override standard base AC:

  • Barbarian Style: 10 + DEX mod + CON mod.
  • Monk Style: 10 + DEX mod + WIS mod.
  • Mage Armor: Flat 13 + DEX mod without equipping physical armor.
Weapon Properties & Action Automation
Core Weapon Property Tags
Auto-Detection

ForgeD checks weapon tags to construct optimal attack macros:

  • Finesse: The macro automatically compares the character's Strength and Dexterity modifiers, selecting whichever is higher.
  • Versatile: Generates two clickable damage buttons in chat: one for standard one-handed strikes (e.g. 1d8) and one for two-handed strikes (e.g. 1d10).
  • Enhancement Bonus: Setting an item bonus (+1, +2, or +3) automatically adds the bonus to both the attack roll and damage total.
  • Damage Riders: Append extra dice (e.g. +1d6 radiant or +2d6 fire) to display distinct damage type badges on hit cards.
Charges & Attunement Slots
Pip Counters

Build wondrous items and artifacts with interactive resource tracking:

  • Attunement Tracking: Check Requires Attunement to enforce the 3-slot attunement limit on the character sheet.
  • Interactive Pips: Define maximum charges (e.g. 7 charges for a Staff of Power) to render clickable consumption bubbles on the equipment tab.
  • Recharge Routines: Select recharge triggers (e.g. 1d6 + 1 at Dawn, Short Rest, or Long Rest).

Spells, Cantrips & Scaling

Magic Studio

ForgeD features automated cantrip scaling, leveled spell slot upcasting, and interactive spell DC cards for all homebrew arcane and divine magic.

Cantrip Level-Scaling Engine

Cantrips automatically scale damage dice according to total character level:

  • Level 1–4: Base damage (e.g. 1d10 fire).
  • Level 5–10: Automatically scales to 2d10.
  • Level 11–16: Automatically scales to 3d10.
  • Level 17–20: Automatically scales to 4d10.

The sheet dynamically detects character level and updates the roll formula without manual intervention.

Leveled Slot Upcasting

Format homebrew spells to support higher-level slot casting:

  • Base Damage: Set the spell level (1st through 9th) and initial damage dice (e.g. 8d6 for 3rd-level Fireball).
  • Higher Level Tag: In the spell description, include standard 5e text: When you cast this spell using a spell slot of 4th level or higher, the damage increases by 1d6 for each slot level above 3rd.
  • Slot Selector: Clicking Cast prompts for the slot level, automatically calculating and rolling the enhanced damage dice into chat.

Custom JSON Compendiums

Source Control

Expand your game universe with external homebrew packages, third-party settings, and community JSON compendiums using ForgeD's Source Manager.

JSON Compendium Directory Architecture

Data File Layout

Place custom homebrew JSON packages into your campaign data directory:

.dndforged-data/
├── sources/
│   ├── bestiary/     (custom monster .json files)
│   ├── spells/       (custom magic .json files)
│   ├── items/        (custom equipment .json files)
│   └── classes/      (custom subclass .json files)
└── sources-config.json

Running the Database Rebuilder

After adding custom JSON packages, compile them into the active game catalog:

  • In the Desktop App: Open the Database Sources tab in the Control Center and click Rebuild Catalogs.
  • Via Developer Terminal: Run npm run build:dbs in the project root.
  • Automatic Deduplication: ForgeD resolves duplicate slugs by prioritizing custom campaign homebrew over core SRD entries.
  • Token Fallbacks: If a creature lacks artwork, ForgeD automatically renders a clean procedural initial-letter badge token on the canvas.
