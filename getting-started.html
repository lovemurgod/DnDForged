Download for Windows

Your first game

Let’s get your table ready.

The Game Master sets up ForgeD on a Windows computer. Everyone else opens the shared game link in a browser.

For the Game Master

Start a game and share the link.

  1. 1

    Download and open ForgeD

    Download the Windows installer and follow the prompts. Open ForgeD VTT when installation finishes.

    Download the Windows app

    If prompted by Windows SmartScreen, click More info and select Run anyway.

  2. 2

    Start your server & online link

    In the app’s Hosting & Server tab, choose Start Server, then select Start Online Tunnel (leave the token blank for recommended quick setup). Wait for your secure player link to appear.

  3. 3

    Open your tabletop & share the link

    Choose Open VTT Window (or Open in Browser) to launch your Game Master view. Click Copy Link in the app and send the active address to your group.

  4. 4

    Get your table ready

    Set a Game Master password in the login window to secure host controls. Then click the Map icon () on the left toolbar to load a battlemap and place character or creature tokens on the grid.

What’s a tunnel?

It’s a secure connection that lets your friends reach the game running on your computer. ForgeD starts it for you; you don’t need to change your router settings.

Cloudflare setup details

For players

Your Game Master sends the link.

Open it in Chrome, Edge, Firefox, or Safari on your computer, tablet, or phone. You don’t need to install ForgeD or create a website account. Enter your Player Name, choose the Player role, and click Enter Campaign. Once inside the table, open your character sheet from the side panel or click your assigned token.

If something gets stuck

A few quick things to check.

The game link isn’t appearing.

Check that the local server is running, then try Start Online Tunnel again. Wait for the app to show the active link before copying it.

My players can’t open the link.

Make sure the computer hosting the game is online and ForgeD remains open with the tunnel active. Copy the current link from the app and send it again.

The link changed after I restarted ForgeD.

A no-token Quick Tunnel uses a temporary link. Copy the new link shown in the app and send it to your players. If you need a stable address, see the optional Cloudflare setup in the Guide.
